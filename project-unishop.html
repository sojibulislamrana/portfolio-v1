    • UniShop — Campus E-Commerce Platform

    Main Technology Stack

    Next.js 16 Node.js Express.js MongoDB Mongoose Tailwind CSS REST APIs

    Project Overview

    UniShop is a modern, student-centric e-commerce platform specifically designed for university campuses. It addresses campus logistical bottlenecks by offering direct-to-dorm delivery, instant checkout, persistent cart management, promo discount workflows, and an administrative dashboard with live revenue metrics and order fulfillment tracking.

    Key Features

    • Curated Student Catalog: Filterable catalog categorized by textbooks, tech accessories, dorm essentials, and stationery.
    • Direct-to-Dorm Logistics: Campus delivery routing with dorm building and room number specifications.
    • Persistent Cart & Live Badges: Client-synchronized cart state that persists across sessions and device refreshes.
    • Discount & Promo Codes: Instant promo validation and dynamic subtotal calculations.
    • Store Management Dashboard: Merchant analytics featuring live revenue tracking, order status updates, and inventory management.
    • Responsive UI: Built with Next.js 16 and Tailwind CSS for instant load times and mobile-friendly usability.

    Engineering Challenges & Solutions

    • Real-Time Inventory Race Conditions: Handled atomic inventory decrementing in MongoDB to prevent double-booking during peak checkout spikes.
    • Cart State Hydration: Solved Next.js SSR hydration mismatches by cleanly synchronizing local storage and backend cart items.
    • API Performance: Implemented lean MongoDB query projections and pagination for responsive mobile browsing.
