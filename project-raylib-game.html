    • Raylib Match-3 Game in C

    Main Technology Stack

    C (C99 Standard) Raylib OpenGL / Hardware Accel Make CMake Native Graphics

    Project Overview

    Raylib Match-3 Game is a native 2D puzzle game implemented in C99 using the Raylib graphics library. Built without heavy commercial game engines like Unity or Godot, this project focuses on low-level game loops, manual 2D array matrix state management, fluid frame-independent animation interpolation, and zero-overhead native compilation.

    Key Features

    • Native C99 Architecture: Written in clean, modular C with explicit memory management and zero garbage collection spikes.
    • Grid Logic & Match Detection: Robust algorithms checking horizontal, vertical, and combo cascade matches across dynamic grid dimensions.
    • Hardware-Accelerated 2D Rendering: Smooth 60fps rendering leveraging Raylib's OpenGL backend.
    • Cascade & Fall Animations: Tweening animations for falling gems and clearing sequences.
    • Score & Multiplier Engine: Tracks chain reaction cascades and combo multipliers.
    • Cross-Platform Build System: Compiles seamlessly via standard Makefile and modern CMake configurations across macOS and Linux.

    Engineering Challenges & Solutions

    • Cascade Chain Reaction Handling: Structured a state machine separating player input, match scanning, gem falling, and empty cell replenishing to avoid infinite loops during multi-chain explosions.
    • Frame-Independent Timing: Implemented delta time (`GetFrameTime()`) calculations so movement speeds remain identical regardless of display refresh rates (60Hz vs 120Hz ProMotion).
